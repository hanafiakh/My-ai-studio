# My AI Studio 🤖

منصتي الشخصية للمحادثة والذكاء الاصطناعي والبرمجة من الهاتف.

## 🚀 المميزات
- 💬 محادثة ذكية متقدمة مع دعم حفظ السجل.
- 💻 مساحة عمل برمجية لإدارة وتعديل الملفات (Code Studio).
- 🔀 توجيه ذكي بين المزودين (Smart Model Router).
- 📱 واجهة متجاوبة بالكامل ومصممة للاستخدام بيد واحدة على Android.
- 🌐 دعم كامل للغة العربية واتجاه RTL والوضع الداكن.

## 🛠️ التقنيات المستخدمة
- **Frontend:** React + TypeScript + Vite + Tailwind CSS
- **Backend:** Cloudflare Workers
- **Database & Auth:** Supabase PostgreSQL & Auth
